Why this could not exist a year ago

You cannot know what a package does without running it, and nobody could afford to run twelve hundred of them in isolation. Forking a live machine now costs a fraction of a cent, so the arithmetic changed — and the timing matters: npm disabled install scripts by default in July 2026, and within six days an attack detonated at import time instead. Reading the source was already behind. Watching it run is the only thing that sees this.

What is real here

Running for real

  • The transcript schema, normalisation, and the behavioural differ — pure and tested
  • Pair running: two twins per package from one checkpoint, waves, every branch released
  • Severity by rules, not by judgement
  • This interface, driven by an actual run

Simulated today

  • The sandbox itself — adapters/simulated.js, a fixed corpus, no network
  • Observation: the strategies are written, none has watched a real kernel yet
  • Nemotron judgement and Tavily evidence — the shapes are fixed, the calls are not wired
