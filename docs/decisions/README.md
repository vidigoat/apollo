# Decisions

Why this project is shaped the way it is. One file per decision that was not obvious, was argued
with, or was reversed. They exist so that someone — a person or an agent — picking this up later
does not re-litigate something already settled, or quietly undo a constraint that is load-bearing.

Each record says what was decided, what it cost, and what would have to be true to change it.
